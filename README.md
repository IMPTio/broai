# Bro

> **Keep their voice alive, privately.**
> A grief-aware memory-preservation app that lets you create AI avatars
> of loved ones to preserve their memories and voice. Privacy-first.

Bro was built in memory of Bronagh English (24 April 2025, aged 18).
This is a personal project before it is a product, and the design
choices — privacy, minimalism, no marketing language inside the
experience — reflect that.
